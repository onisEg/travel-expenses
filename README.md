# Travel Expenses Calculator

A TypeScript project to calculate budget status and manage travel expenses.

## Features
- Budget calculation and status reporting.
- Daily expense reports.
- TypeScript types and interfaces.
- Input validation and error handling.

## Technologies
- TypeScript
- Vite
- HTML5

## Getting Started

```bash
npm install
npm run dev
```

## Run the Budget Calculator

```bash
npx vite-node src/budgetCalculator.ts
```

**Project:** TypeScript learning exercise — Iterations 1, 2, and Calculator Interface (Bonus Track).
